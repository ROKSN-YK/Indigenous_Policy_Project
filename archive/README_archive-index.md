## 封存原則

- 新版資料或程式碼進入正式工作目錄前，先將被取代的舊版完整移至當日日期資料夾 `archive/YYYY-MM-DD/`。
- 日期資料夾內應保留原本的相對目錄結構，並以說明檔記錄來源、整併範圍與未納入項目。
- 若新版離線包因限制性資料攜出原則未包含某些資料，正式工作目錄中的必要原始資料或中間資料不予替換或封存，直到取得可合法整併的新版。
- 封存只改變檔案位置，不刪除內容；後續調整一律以正式工作目錄中的最新版為基準。
