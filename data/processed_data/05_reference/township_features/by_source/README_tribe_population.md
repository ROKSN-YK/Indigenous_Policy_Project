# 鄉鎮×族別原住民人口（戶政司開放資料）

來源：內政部戶政司「現住原住民人口按性別、身分、原住民族別分」（村里層級，加總到鄉鎮）
- 104/12、105/12：data.gov.tw 資料集 32971 的 CSV（opdadm.moi.gov.tw 下載）
- 106/12：API ODRP009（只提供 106/01–12、110/01、111/01–02）
- 107/12–114/12、115/09：API ODRP018（新增區域代碼；107/01–115/09 每月）
- API 說明：https://www.ris.gov.tw/rs-opendata/api/Main/docs/v1 ；路徑 /rs-opendata/api/v1/datastore/{ODRP009|ODRP018}/{民國年月}?page=N（每頁 2,000 筆村里）
- 114 年起欄位改名（indigenous_*、pinuyumayan、cou、hlaalua，並新增平埔族群）；本表 tot＝平地＋山地原住民，不含平埔，以維持可比。
- 104/12 以前沒有開放資料（API 回傳「查無資料」）。

欄位：ym、site（縣市鄉鎮）、code（8 碼鄉鎮代碼，107 年起）、tot、plain、mtn、17 族別合計與 p_（平地原住民）、m_（山地原住民）分項；county_std/town_std/area_type 由 township master 對上（44 筆非原鄉名稱含全形空白或已整併，未對上）。
