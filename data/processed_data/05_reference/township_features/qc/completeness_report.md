## 三、90–95 年總人口（OCR）怎麼確認正確

來源是國家圖書館「政府統計資訊網」的《中華民國臺閩地區人口統計》90–94 年、《中華民國人口統計年刊》95 年，表二「各縣市鄉鎮市區年底人口數按性別及五歲年齡組分」（每年 50 頁掃描檔）。

每個鄉鎮都過三道核對，全部通過才收：
1. 男＋女＝計（27 欄逐欄）。
2. 各年齡組加總＝總計。
3. 1–4 歲小計＝1＋2＋3＋4 歲。

另外，縣市合計列（獨立辨識）與其轄下鄉鎮加總逐欄比對，六年全部一致；全國總數也與官方公布數一致。

- 原民會 95–98 年的檔案把「苓雅區」寫成「芩雅區」，已更正。
- 原民會 92 年臺南市的中區、西區還是分開列，已加總成中西區。
