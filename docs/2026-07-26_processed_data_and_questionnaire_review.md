# Processed Data 與問卷選項覆核

## 整理結果

`data/processed_data` 現行內容分為（詳細說明見
`data/processed_data/README_processed-data-structure.md`）：

1. `01_documentation`：流程與分析說明。
2. `02_metadata`：年度 metadata、問卷選項與年度比較。
3. `03_crosswalks`：正式 crosswalk 與人工維護參照表。
4. `03_income_expense`：正式所得／支出產出。
5. `04_analysis_ready`：跨年分析資料與 DID 準備檔。
6. `05_reference`：摘要表與後續分析參考檔。
7. `archive`：已退出程序的舊成果。

根目錄三個 `*_from_02.rds` 是正式遠端程序中間產出，應保留。
檔案內容雜湊檢查未發現完全相同的重複檔。

本次已歸檔六個舊版所得／支出 RDS，現行程序只接受
`03_income_expense/income_expenditure_data.rds`。

## 問卷選項覆核

### 2002 年

兩份問卷為掃描 PDF。本次已逐頁視覺核對並補入：

- 性別、年齡、教育、族別、婚姻、配偶原住民身分。
- 職業、行業、工作身分、住宅結構與住宅所有權。
- 房租、房貸、家庭所得與家庭支出級距。
- 配偶工作、政府協助與貸款意願等封閉式選項。
- 第二次問卷新增的噶瑪蘭族、職業細分、鐵皮屋、未經許可自行搭建、
  教育書報支出與旅遊娛樂支出。

問卷第 19 題把最高兩個租金級距都印成代碼 `6`。本專案保留問卷原貌，
不擅自改成 `7`；離線處理須優先使用原始 DTA 的 value label，若遠端
原始欄位確實也是重複代碼，則以標籤文字辨識並輸出覆核表。

### 其他年度

已確認並保留先前修正：

- 2006 性別與開放填答欄位處理。
- 2014 教育代碼 7、8、9 均歸為專科以上。
- 2014 H2/H3 及支出表格被 PDF 文字層合併的選項。
- 2017 M7 選填空白不視為 0 元。
- 2021 相同格式的所得／支出表格修正。

問卷抽取品質表目前為零筆錯誤；測試會檢查 2002 兩版本的主要選項、
版本差異、租金印刷重碼，以及 2014、2017、2021 的既知修正。

## 尚待遠端資料確認

2002 第 19 題租金最高級距的原始 value code、2006 開放填答欄位實際
儲存型態，以及各年度原始值標籤與目前表格是否完全一致，仍須在離線
遠端環境執行正式驗證程序後才能做最終確認。
